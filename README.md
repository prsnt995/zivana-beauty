# Zivana Beauty

An e-commerce web application for Zivana Beauty, featuring a modern shopping experience for skincare, makeup, haircare, and fragrance products.

## Features

- **Product Catalog & Browsing**: Explore beauty categories, best sellers, and new arrivals.
- **Interactive Shopping**: Product details, customer reviews, and cart management.
- **Checkout & Payment**: Seamless checkout flow with simulated Google Pay gateway.
- **User Accounts & Admin Dashboard**: Account management, order tracking, and administrative controls.
- **Responsive UI**: Optimized for desktop, tablet, and mobile devices.

## Tech Stack

- **React 18**
- **Vite**
- **Lucide Icons**
- **Canvas Confetti**

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed.

### Installation

```bash
npm install
```

### Development

Run the local development server:

```bash
npm run dev
```

### Build

Create a production build:

```bash
npm run build
```
